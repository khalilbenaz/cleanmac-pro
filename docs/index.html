Installer en 3 commandes.

Prérequis : Xcode 15 ou macOS Command Line Tools (Swift 5.9+).

git clone https://github.com/khalilbenaz/cleanmac-pro.git
cd cleanmac-pro
swift build -c release
# Optionnel : génère le bundle .app signé ad-hoc et l'installe
./Tools/build-app.sh
cp -R "build/CleanMac Pro.app" /Applications/
